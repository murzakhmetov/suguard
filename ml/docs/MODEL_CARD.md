# Model card — SuGuard ML v0.1.0

Исследовательский прототип. Не медицинское изделие, не для диагностики и подбора лечения.

## 1. Denoiser (очистка PPG от движения) — `models/denoiser.onnx`

| | |
|---|---|
| Назначение | Убрать артефакты движения из сырых окон MAX30102 (red + IR) перед расчётом ЧСС, SpO2 и признаков формы пульса; отметить участки, где пульс восстановить нельзя |
| Архитектура | 1D U-Net, 457 267 параметров; вход (2, 512) = IR и red, 10.24 с при 50 Гц, общая нормировка; выход: чистые IR, red и логит маски артефактов |
| Обучение | 150 000 окон симулятора MAX30102 (`synth/ppg.py`): модель пульса с HRV, дыхательной модуляцией, эктопией; оптика red/IR по SpO2 82–99.5 %; перфузия 0.08–5 %; движение: ходьба/бег (в т.ч. на частоте пульса), всплески, ступеньки давления, спайки, дрейф, потеря контакта; шум, 18-бит квантование, насыщение АЦП |
| Потери | L1 по форме + L1 по производной + BCE маски + ошибка отношения red/IR |
| Проверка | отложенные 4 000 окон симулятора (другие seed); реальные PPG-записи (heartpy) с наложенной оптикой/движением; в Colab — реальное движение PPG-DaLiA |
| Результаты | DENOISER_CARD |
| Ограничения | Обучена на симуляции: реальные артефакты конкретного корпуса SuGuard могут отличаться. Без акселерометра различает движение только по форме и соотношению red/IR. При сплошном движении сеть «дорисовывает» правдоподобный пульс — поэтому значения выдаются только если маска артефактов покрывает ≤ 50 % окна. Перед использованием в продукте — проверить на записях своего браслета с эталонным пульсоксиметром/ЭКГ |

## 2. SpO2

Отношение отношений R по очищенным сигналам (взвешенная регрессия red на IR), кривая Maxim RD117
`SpO2 = −45.060·R² + 30.354·R + 94.845`. **Не откалибровано под корпус SuGuard** — нужна калибровка по
медицинскому пульсоксиметру (`fit_spo2_calibration`); значения < 90 % требуют лабораторной проверки
(ISO 80601-2-61).

## 3. Риск диабета — `models/risk_model.json` (v1.1.0)

| | |
|---|---|
| Назначение | Скрининговая оценка вероятности повышенного HbA1c у взрослого **без диагноза** (не диагноз, не прогноз на будущее) |
| Выход | P(HbA1c ≥ 5.7 %), P(HbA1c ≥ 6.5 %), P(5.7–6.4 %), `risk_score` = 100·P(HbA1c ≥ 5.7 %), категория low / moderate / elevated / high, вклад указанных пользователем факторов, список неиспользованных входов |
| Модель | Логистическая регрессия (L2, C = 1): возраст (+квадрат), пол, log ИМТ, пульс в покое, физическая активность, происхождение (азиатское — с взаимодействием с ИМТ; европейское). Неуказанные пол/активность/происхождение маргинализуются по долям NHANES, пульс импутируется из возраста/пола/ИМТ. Возраст ограничен диапазоном данных (18–80) |
| Данные | NHANES 2017–2018, 4 318 взрослых без диагноза/лечения диабета, с HbA1c и ИМТ; HbA1c ≥ 5.7 % у 34.0 %, ≥ 6.5 % у 3.6 % |
| Проверка | Повторённая стратифицированная 5-кратная CV (5 повторов), импутация внутри фолда, out-of-fold метрики, bootstrap 95 % ДИ, калибровка по подгруппам |
| HbA1c ≥ 5.7 % | AUC 0.770 [0.756–0.783], AP 0.594, Brier 0.180 (без модели 0.224), наклон калибровки 1.00 |
| HbA1c ≥ 6.5 % | AUC 0.789 [0.749–0.815], AP 0.113 (распространённость 0.036), Brier 0.033 (0.034), наклон 0.97 |
| Сравнение | только возраст + ИМТ: 0.748 / 0.749; без происхождения: 0.749 / 0.756 |
| Калибровка по подгруппам | азиаты 0.382 предсказано / 0.383 наблюдается; европейцы 0.277 / 0.277; 18–39 лет 0.142 / 0.144; 60–80 лет 0.534 / 0.533; **чернокожие 0.40 / 0.46 и мексиканцы 0.34 / 0.29 — систематика остаётся** |
| Категории (out-of-fold) | low: 32 % людей, HbA1c ≥ 5.7 % у 9 %; moderate: 27 % / 30 %; elevated: 27 % / 50 %; high: 14 % / 66 % (HbA1c ≥ 6.5 % у 11 % — в 3 раза выше среднего) |
| Отброшено | Талия (r = 0.91 с ИМТ, неустойчивый знак) и курение (в поперечных данных NHANES получает ложный «защитный» знак): не улучшают AUC и не должны объяснять риск; если их передать, API вернёт их в `inputs_not_used` |
| Глюкоза браслета | Выключена: используется только при модели глюкозы, валидированной на этом браслете (сервер знает её ошибку). Тогда — HbA1c по ADAG = (средняя + 46.7)/28.7 и байесовское обновление с распределениями HbA1c по классам NHANES. GMI не используется: в норме он завышает HbA1c (~5.7 % при средней 100 мг/дл) |
| Ограничения | Популяция США, невзвешенная выборка (взвешенный вариант — `--weights DEMO_J.xpt` в Colab). Для Казахстана калибровку нужно подтвердить на местных данных с HbA1c. Нет семейного анамнеза, гестационного диабета, давления — сильных факторов опросников ADA/FINDRISC (стоит добавить в анкету) |

## 4. Глюкоза — `models/glucose_*.txt` (не обучена)

| | |
|---|---|
| Назначение | Оценка глюкозы по признакам PPG + контексту с персональной калибровкой по глюкометру |
| Модель | LightGBM: медиана + квантили 10/90 %; калибровка — фильтр Калмана на y = a + b·f с дрейфом параметров; вход — медиана признаков ≥ 3 надёжных 10.24-с окон (одинаково при обучении и в API) |
| Статус | **Не обучена**: в разрешённых источниках нет парных данных PPG ↔ глюкоза. API отдаёт `unavailable`, после ≥ 3 уколов — `calibration_only` (среднее уколов, `mg_dl = null`) |
| Критерий `validated` | данные браслета SuGuard; ≥ 20 человек; на новых людях MARD лучше «среднего» на ≥ 10 %; после калибровки лучше лучшей базовой модели без PPG (уровень по уколам, последний укол, личный суточный профиль) на ≥ 10 % с нижней границей bootstrap-ДИ > 0; PPG лучше контролей «только контекст» и «PPG перемешан» на ≥ 5 %; MARD ≤ 15 % и Кларк A+B ≥ 99 % после калибровки; то же на запертой отложенной группе людей |
| Планка (реальные CGM) | преддиабет/СД (19 чел.): константа MARD 16.9 %, калибровка Калмана 15.1–16.1 %; СД2 (5 чел.): 35 % / 21.6 % |
| Проверка логики | синтетические положительный и отрицательный контроли (`tests/synthetic_paired.py`): настоящий сигнал проходит все доказательные критерии, шум — нет; синтетика никогда не получает `validated` (не данные браслета) |
