# Model card — SuGuard ML v0.1.0

Исследовательский прототип. Не медицинское изделие, не для диагностики и подбора лечения.

## 1. Denoiser (очистка PPG от движения) — `models/denoiser.onnx`

| | |
|---|---|
| Назначение | Убрать артефакты движения из сырых окон MAX30102 (red + IR) перед расчётом ЧСС, SpO2 и признаков формы пульса; отметить участки, где пульс восстановить нельзя |
| Архитектура | 1D U-Net, 457 267 параметров; вход (2, 512) = IR и red, 10.24 с при 50 Гц, общая нормировка; выход: чистые IR, red и логит маски артефактов |
| Обучение | 150 000 окон симулятора MAX30102 (`synth/ppg.py`): модель пульса с HRV, дыхательной модуляцией, эктопией; оптика red/IR по SpO2 82–99.5 %; перфузия 0.08–5 %; движение: ходьба/бег (в т.ч. на частоте пульса), всплески, ступеньки давления, спайки, дрейф, потеря контакта; шум, 18-бит квантование, насыщение АЦП |
| Потери | L1 по форме + L1 по производной + BCE маски + ошибка отношения red/IR |
| Проверка | отложенные 4 000 окон симулятора (другие seed); реальные PPG-записи (heartpy) с наложенной оптикой/движением; в Colab — реальное движение PPG-DaLiA |
| Результаты | DENOISER_CARD |
| Ограничения | Обучена на симуляции: реальные артефакты конкретного корпуса SuGuard могут отличаться. Без акселерометра различает движение только по форме и соотношению red/IR. При сплошном движении сеть «дорисовывает» правдоподобный пульс — поэтому значения выдаются только если маска артефактов покрывает ≤ 50 % окна. Перед использованием в продукте — проверить на записях своего браслета с эталонным пульсоксиметром/ЭКГ |

## 2. SpO2

Отношение отношений R по очищенным сигналам (взвешенная регрессия red на IR), кривая Maxim RD117
`SpO2 = −45.060·R² + 30.354·R + 94.845`. **Не откалибровано под корпус SuGuard** — нужна калибровка по
медицинскому пульсоксиметру (`fit_spo2_calibration`); значения < 90 % требуют лабораторной проверки
(ISO 80601-2-61).

## 3. Риск диабета — `models/risk_model.json`

| | |
|---|---|
| Назначение | Скрининговая оценка вероятности преддиабета/диабета у взрослого **без диагноза** |
| Выход | P(HbA1c ≥ 5.7 %), P(HbA1c ≥ 6.5 %), P(5.7–6.4 %), категория low / moderate / elevated / high, вклад факторов |
| Модель | Логистическая регрессия (L2, C = 1) на: возраст (+квадрат), пол, log ИМТ, пульс в покое, физическая активность. Отсутствующие входы маргинализуются (пол, активность — по распространённости NHANES; пульс — линейная импутация из возраста/пола/ИМТ) |
| Данные | NHANES 2017–2018, 4 318 взрослых ≥ 18 лет без диагноза/лечения диабета, с измеренными HbA1c и ИМТ; HbA1c ≥ 5.7 % у 34.0 %, ≥ 6.5 % у 3.6 % (недиагностированный диабет) |
| Проверка | Повторённая стратифицированная 5-кратная CV (5 повторов), импутация внутри фолда, out-of-fold метрики, bootstrap 95 % ДИ |
| HbA1c ≥ 5.7 % | AUC 0.749 [0.735–0.764], AP 0.561, Brier 0.187 (без модели 0.224), наклон калибровки 1.00 |
| HbA1c ≥ 6.5 % | AUC 0.756 [0.718–0.785], AP 0.104 (распространённость 0.036), Brier 0.033 (без модели 0.034), наклон 0.99 |
| Вклад пульса | для недиагностированного диабета AUC 0.743 → 0.756 (ДИ перекрываются; OR ≈ 1.46 на +12 уд/мин) |
| Категории (out-of-fold) | low: 30 % людей, HbA1c ≥ 5.7 % у 9 %; moderate: 27 % / 31 %; elevated: 32 % / 50 %; high: 11 % / 63 % (≥ 6.5 % у 10 % — в 3 раза выше среднего) |
| Отброшено | Талия (r = 0.91 с ИМТ, неустойчивый знак) и курение (в поперечных данных NHANES получает ложный «защитный» знак): не улучшают AUC и не должны объяснять риск в приложении |
| Глюкоза браслета | Учитывается только при известной проверенной ошибке: GMI = 3.31 + 0.02392·средняя глюкоза → байесовское обновление с распределениями HbA1c по классам из NHANES (SD расхождения GMI–HbA1c 0.45 %) |
| Ограничения | Популяция США; калибровку для Казахстана нужно проверить на местных данных. Поперечное исследование: модель оценивает «есть ли сейчас», а не «будет ли». Нет семейного анамнеза, гестационного диабета, давления — сильных факторов из опросников ADA/FINDRISC (их стоит добавить в анкету приложения) |

## 4. Глюкоза — `models/glucose_*.txt` (не обучена)

| | |
|---|---|
| Назначение | Оценка глюкозы по признакам PPG + контексту, с персональной калибровкой по глюкометру |
| Модель | LightGBM: медиана + квантили 10/90 %; калибровка — фильтр Калмана на y = a + b·f с дрейфом параметров |
| Статус | **Не обучена**: в разрешённых источниках нет парных данных PPG ↔ глюкоза. API отдаёт `unavailable` или `calibration_only` (уровень по последним уколам, явно помеченный) |
| Критерий `validated` | на новых людях выигрыш MARD ≥ 10 % у «среднего»; на будущих днях после калибровки — ≥ 10 % у лучшей «только калибровки»; PPG-признаки дают ≥ 5 % сверх модели «только контекст» |
| Планка (реальные CGM) | преддиабет/СД (19 чел.): константа MARD 16.9 %, калибровка Калмана 15.1–16.1 %; СД2 (5 чел.): 35 % / 21.6 % |
